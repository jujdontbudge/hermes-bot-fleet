# Hermes Bot Fleet Domain

## Bot Fleet

The complete personal system of independently configured Hermes Bots across the Server Runtime and Laptop Runtime.

## Bot

A Hermes profile with its own identity, instructions, memory, sessions, capabilities, routines, and messaging state.

## Chief

The primary always-on Server Bot that coordinates work and delegates to other Bots.

## Laptop Worker

A Bot owned by the Laptop Runtime that performs approved tasks against resources available only on the Mac.

## Server Runtime

The persistent Hermes installation hosted on the Azure Ubuntu server.

## Laptop Runtime

The Hermes installation running on Johan's Mac while it is awake and connected.

## Browser Profile

A persistent, Bot-scoped server-side browser identity containing only the accounts and state deliberately granted to that Bot.

## Browser Takeover

A temporary handoff in which Johan views and controls a Bot's server-side browser for authentication, CAPTCHA, inspection, or intervention.

## File Bridge

A private, allowlisted interface through which an authorized Server Bot can operate on approved Mac folders while the Laptop Runtime is reachable.

## Channel

An external messaging transport such as Telegram, Discord, or Slack. This is distinct from a Bot Room inside Hermes Desktop.

## Bot Room

A Hermes Desktop conversation containing multiple Bots and optionally a human, supporting mentions and cross-machine collaboration.

## Capability Parity

A verified mapping from a Grok Bot capability to either a native Hermes capability, an implemented equivalent workflow, or an explicitly documented unsupported gap.
